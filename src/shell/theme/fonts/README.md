# Fonts

`wine-tahoma.ttf` and `wine-tahoma-bold.ttf` are Wine's free Tahoma (`tahoma.ttf`, `tahomabd.ttf`
from `../references/wine-fonts/`), metric-compatible with Microsoft's. They're licensed under the
LGPL 2.1 (`COPYING.LIB`) and loaded as the family `Wine Tahoma`, listed after `Tahoma` so systems
that have the real font use it.
